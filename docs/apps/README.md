# Documentação das aplicações

Este diretório organiza a documentação de desenvolvimento de cada unidade
executável localizada em `apps/`.

## Aplicações atuais

- [API](./api/README.md);
- [Web](./web/README.md);
- [Mobile](./mobile/README.md).

Quando uma nova aplicação for adicionada, crie também
`docs/apps/<nome>/README.md` para documentar seu objetivo e, conforme as
decisões surgirem, sua arquitetura, execução, testes e operação.

O processo geral para criar uma aplicação ou package está em
[Adicionando aplicações e pacotes](../adding-apps.md).
