# Contribuindo

1. Crie uma branch curta e focada.
2. Nunca versione arquivos `.env` nem credenciais.
3. Adicione ou atualize testes junto com a mudança.
4. Execute `pnpm check` e `pnpm format:check` antes de abrir a revisão.
5. Inclua migrations Prisma quando o schema mudar e nunca edite uma migration já aplicada.

Commits e pull requests devem explicar a intenção da mudança, não apenas listar arquivos alterados.
